MEMBER PICTURES
===============

One image per member. Square works best (they are shown in a circle).
png / jpg / webp are all fine.

Wire it up in js/members.js:

    { alias: 'METE', rank: 'MANAGEMENT', status: 'ACTIVE', img: 'img/mete.png' },

Leave "img" out and a sigil is generated from the alias instead.
If the file is missing, the sigil takes over automatically - no broken
image icon, no error.
